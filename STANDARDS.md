# Standards

Every resource included in BlackBit OSINT must meet most of the following criteria.

## Required

* Official website.
* Actively maintained.
* Provides real value in professional investigations.
* Stable and reliable.
* Accessible without unnecessary barriers.
* Properly categorized.

## Preferred

* Free or offers a useful free tier.
* Well documented.
* Trusted by the OSINT or security community.
* Regularly updated.
* Cross-platform.

## Excluded

The following resources will not be included:

* Dead links.
* Abandoned projects.
* Duplicate tools without clear advantages.
* Promotional websites.
* Low-quality directories.
* Collections that simply aggregate other collections.
* Tools with no practical investigative value.

## Golden Rule

A resource is not included because it exists.

It is included because it is one of the best choices for a specific investigative task.
