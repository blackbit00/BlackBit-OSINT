# BlackBit OSINT

> **Collect less. Discover more.**

A curated collection of verified OSINT resources for professional investigations.

Every resource included in this repository is manually reviewed before inclusion, validated through AI-assisted research, and selected because it provides real value in investigative workflows.

We don't aim to build the biggest OSINT repository.

We aim to build the one you'll actually use.

---

## Philosophy

Every tool should have a purpose.

Every bookmark should save time.

Every resource should earn its place.

Quality over quantity.

Precision over popularity.

---

## Principles

* Official resources only.
* Human-reviewed selection.
* AI-assisted research and validation.
* No duplicate tools.
* No abandoned projects.
* No sponsored listings.
* Practical workflows.
* Continuously maintained.

---

## What You'll Find

* Curated bookmarks.
* Professional OSINT tools.
* Investigation workflows.
* Browser extensions.
* Desktop applications.
* Learning resources.

Every category is designed to answer a single question:

**"What's the best tool for this job?"**

---

## Contributing

Contributions are welcome.

Before opening a Pull Request, please ensure that the resource:

* Uses the official website.
* Is actively maintained.
* Provides unique value.
* Fits the philosophy of this project.
* Has been personally tested whenever possible.

Quality will always take priority over quantity.
