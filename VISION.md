# Vision

BlackBit OSINT exists to solve one problem:

There are too many OSINT resources, but very few curated collections that prioritize quality over quantity.

This project only includes resources that provide real value during investigations.

Every tool should have a purpose.

Every bookmark should save time.

Every resource should earn its place.

Our goal is not to become the largest OSINT repository.

Our goal is to become the most trusted one.
